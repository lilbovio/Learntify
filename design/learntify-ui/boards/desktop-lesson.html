Values become expressions

Predict a value before running a program, then verify how JavaScript computes it.

A value is a fundamental piece of information in JavaScript, such as the number 3 or the text "hello".

An expression is any valid unit of code that resolves to a value. When JavaScript encounters 2 + 3, it evaluates the arithmetic operation first to produce 5.

console.log() displays a value in the output area. Quotation marks delineate strings of text; they are never printed in the actual output.
